# UI Information Architecture

## Main Areas

- Core Setup
- Variable Mapping
- Output Choices
- Import ini
- Template Management
- Advanced Options
- Generated Result

## Advanced Grouping Rule

Advanced functionality is grouped into a single visible section.
There is no beginner versus expert mode split in the first release.

## Shared Host Behavior

- Web and desktop share the same section order.
- Template management sits outside the core form but before generation.
- Result generation and export stay in the right column on desktop-sized screens.
